
# ATM-Simulator

A basic ATM simulation program developed in C++.

## Features
- PIN verification
- Balance enquiry
- Deposits and withdrawals
- Insufficient-balance checks
- Menu-driven interface

## Technologies
- C++
- Conditional statements
- Loops and switch-case

## Run
Compile: `g++ main.cpp -o atm`
Run: `./atm` (Windows: `atm.exe`)

## Note
This is an educational simulation, not a real banking application.
